# Prompts (AI Summary Layer)

AuditAI uses LLMs only for a narrow purpose: generating an **executive summary narrative** of a deterministic audit report.

The numeric savings calculations and recommendations are generated by a rule engine, not by the LLM.

---

## Responsible AI Usage

This repo intentionally constrains AI usage to reduce cost, drift, and misinformation:

### 1) The system prompt constrains what the model is allowed to do

The API uses a fixed system prompt (`lib/ai/prompts.ts`) that instructs the model to:

- use only the provided numbers and recommendations
- never invent or calculate savings itself
- output plain text (no markdown)
- keep output concise (~100 words)

### 2) Provider output is sanitized and validated

`lib/ai/generateAuditSummary.ts` applies deterministic post-processing:

- strips any accidental markup (`sanitizeSummaryText`)
- clamps output to a maximum word budget (`clampWords`)
- validates output quality before accepting the result

### 3) Deterministic fallback prevents “blank” narrative experiences

If:

- provider keys are missing
- the provider call fails
- output is empty/invalid or rejected by heuristics

the system generates a deterministic fallback summary using `fallbackSummary()` (also based on the deterministic recommendations).

### 4) Time-bounded provider calls

Both OpenAI and Anthropic providers abort the request after ~8 seconds (`AbortController`).

---

## Prompt Engineering Approach

### System prompt (hard constraints)

`SYSTEM_PROMPT` is an array joined into a single string with these themes:

- “You are AuditAI…”
- “Use only provided numbers and recommendations”
- “Never invent or calculate savings yourself”
- “Output plain text (no markdown)”
- “Limit to ~100 words”

### User prompt (structured deterministic context)

`buildUserPrompt(payload)` creates a user message by combining:

- team size and primary use case
- savings state based on deterministic totals (`monthlySavings` / `annualSavings`)
- top recommendations sorted by `estimatedSavings` (top 3)

Each recommendation is formatted as:

- index
- tool name
- recommended action
- savings approximation (`≈<estimatedSavings>/month` or `0 savings`)
- one-sentence deterministic reason

This reduces hallucination opportunities because the model is given a small, curated, numeric list to summarize.

---

## Where AI Is Intentionally NOT Used

AI is intentionally excluded from:

- savings math and recommendation generation
- numeric totals (`monthlySavings` / `annualSavings`)
- recommendation selection and deduplication

Those parts are computed by:

- `lib/audit/engine.ts`
- `lib/audit/rules.ts`
- pricing assumptions in `lib/audit/pricing.ts`

The LLM layer is only a narrative transformation of already-computed deterministic outputs.

---

## Limitations Encountered

Even with constraints and fallback, practical limitations remain:

1. **Provider output can be empty or too short**
  - The code clamps and applies a minimum word-count heuristic; if it fails, the app uses deterministic fallback.
2. **Output formatting drift**
  - Models can accidentally output markup; `sanitizeSummaryText()` removes tags, but the output may still fail heuristics.

## Example Prompts

### Example system prompt (from `SYSTEM_PROMPT`)

```text
You are AuditAI, an expert assistant for startups.
Write a concise executive audit summary.
Use only the provided numbers and recommendations.
Never invent or calculate savings yourself.
Output plain text (no markdown), professional and actionable.
Limit to ~100 words.
```

### Example user prompt (from `buildUserPrompt()`)

Assume a deterministic payload that produced:

- `teamSize = 6`
- `primaryUseCase = "coding"`
- `monthlySavings = 120`
- top recommendations:
  - (1) `Cursor`: `Downgrade from BUSINESS to PRO` (≈$100/month), reason: “Your team size…”
  - (2) `ChatGPT`: `Consolidates to one assistant…` (≈$20/month), reason: “These assistants…”

Then the prompt would look like:

```text
Team size: 6
Primary use case: coding
Potential savings: 120/month (1440/year).

Top recommendations (use these only):
1. Cursor: Downgrade from BUSINESS to PRO (≈100/month). Reason: Your team size (6) is below the typical range for BUSINESS, so you’re likely paying for admin features you don’t need.
2. ChatGPT: Switch to a single assistant (keep ChatGPT, cancel Claude) (≈20/month). Reason: These assistants overlap strongly in day-to-day usage, so one subscription is usually sufficient.

Write the summary now.
```

## Notes on Future Prompt Improvements

If you later add new narrative sections (e.g., “top 3 wins” vs “risks”), keep the same discipline:

- deterministic numeric inputs only
- strict system prompt constraints
- sanitization + fallback
